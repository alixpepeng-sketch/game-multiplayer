# ALYZ MULTIPLAYER
Setup: 1) Firebase Console > Authentication > aktifkan Google. 2) Realtime Database > buat database > tab Rules > tempel database.rules.json > Publish.
3) Isi js/firebase-config.js. 4) Authentication > Settings > Authorized domains > tambahkan domain Vercel. 5) Deploy folder ini ke Vercel (Framework: Other, tanpa build).
Uji lokal: npx serve .
